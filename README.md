# Guess-a-Number

A simple game to see if the user can guess the number that the program thinks off. 

To install: 
- Clone the GitHub repo, change to the directory, and install dependencies using `npm i`

To run:
1. Once in the game directory, run `node game.js`
2. Enter a valid option from rock, paper, or scissors.
3. Type `quit` to exit.

Future features:
- Add additional error tracking 
- Create a web version using HTML.
